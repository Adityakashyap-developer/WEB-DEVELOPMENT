Now we are going to learn about HTML TAGS.

What is a tag?

A tag is a keyword written inside angle brackets (<>).
Tags tell the browser how to display the content.

There are two types of tags:

1. Opening tag

2. Closing tag

The opening tag is the first tag in a pair of tags. It is used to start an element.
The closing tag is the second tag in a pair of tags. It is used to end an element.
The closing tag has a forward slash (/) before the tag name.

Commonly Used Tags

• Br Tag is used to insert a line break.

• Hr Tag is used to insert a horizontal rule.

• Marquee Tag is used to create a creat scrolling text.
