# HTML Complete Notes 📘

1. Introduction to HTML

HTML stands for HyperText Markup Language. It is the standard markup language used to create the structure of web pages.

HTML defines elements such as headings, paragraphs, images, links, tables, and forms.
Uses of HTML
• To create web pages.
• To add text, images, and links.
• To create tables and forms.
• To structure website content.
• To work with CSS and JavaScript.
